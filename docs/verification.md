# 第一版实现验证

日期：2026-09-16。

追加：当日已完成两个模型各一次真实生成，结果与边界见 [真实测试记录](live-test-2026-09-16.md)。下文“尚未验证”中的无 Key 说明是首轮离线实现的历史状态；余额接口和其他模型组合仍未真实验证。

## 目标环境

- ComfyUI `v0.36.0`，提交 `ee71d5c4993f29086b27fde1629a945ae48425bf`。
- 配套 `comfyui-frontend-package 1.52.7`；对应前端源码提交 `1a7a6b82514874545dc5e8203d0bd2188c2d9b18`。
- 本机隔离 Python 3.12.13 环境，CPU 模式，PyTorch 2.14.0；没有修改用户的现有 ComfyUI 安装。
- 核对来源：官方仓库 release 元数据、该 tag 的 requirements、V3 `_io.py`、`execution.py`、缓存实现和前端动态控件源码。

## 已验证

最终回归：70 项 Python 测试（包含 12 项真实宿主集成测试）、3 项 JavaScript 状态测试，以及真实前端浏览器 smoke 测试通过；Ruff 与 `git diff --check` 通过。

- 离线 aiohttp mock：提交一次、同 ID 轮询、503 退避、终态/协议失败、POST 响应丢失不重发、下载认证隔离、部分结果失败整体报错。
- pending POST、pending GET、429 Retry-After 退避、pending 下载均在测试中小于 1 秒响应取消。取消后等待 HTTP 任务退出并关闭会话。
- 虚拟轮询时钟累计 900 秒后仍可成功；默认配置没有总截止时间。另测试显式总截止时间，保留已知任务 ID。没有进行实际 15 分钟墙钟长测。
- 配置校验：版本、引用、重复模型/选项、家族字段、默认值、传输参数；用户配置优先、不可变执行快照。
- 图像：无图、单图、批次、异尺寸列表保序编码，非法输入整体失败，RGB 输出保尺寸，非不透明 alpha 拒绝。
- 真正的 ComfyUI V3 包装和执行器：动态参数为字典内列表；以上四类图片输入各仅调用一次生成。
- 真正的 PromptExecutor、PreviewImage、SaveImage：相同输入两个节点不合并，连续两个 prompt 共执行四次；两个异尺寸输出均保存/预览，不缩放。
- 真正的节点适配加 mock 网络：成功/远端失败后刷新余额一次；校验失败/中断不查询；图片先返回，余额 endpoint 可继续独立等待；0 积分有效。
- 真实前端 Chrome：模型切换保留合法参数、失效参数使用默认、隐藏无关控件、单选项禁用且值可见；工作流节点保存重载；删除模型/参数保留原值而不是默默更换。
- 浏览器事件：0 积分、旧序号隔离、换 Key 后旧事件无效；余额不在序列化输入中。不在浏览器调用 GRSAI。
- 扩展真实启动加载成功，浏览器测试无 page error。

## 尚未验证

- 没有提供/读取真实 API Key，没有调用 GRSAI 生成、余额或其他计费接口。
- 新接口接受裸 PNG base64 的实际行为、七个模型各参数组合、真实输出格式和上游错误样本仍需授权联调。
- 未验证其他 ComfyUI/前端版本、第三方 IMAGE list 节点、子图内状态定位、Vue 节点渲染模式和远程非安全上下文浏览器。
- 未做大图片内存压力测试；没有把本地图片数量限制伪装成平台限制。

## 复现

`tests/test_host.py` 在未设置 `COMFYUI_PATH` 时明确跳过；不会用伪造的 ComfyUI API 替代宿主验证。`tests/browser_smoke.py` 要求单独启动 ComfyUI 与本机 Chrome，不会自动生成图片。

余额后台任务由宿主服务器事件循环持有；同节点旧查询取消并等待清理，服务器清理时取消全部查询。节点输入和结果仍遵循原生执行队列，界面刷新不入队。
